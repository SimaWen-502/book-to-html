# 第一版公开发布核查

核查日期：2026-10-10。发布范围为 `book-to-html` 第一版技能及公开版补充文件，保留第一版 CSS 和浏览器阅读交互。

## 核查结果

原版技能的全部 11 个文件经过完整静态阅读和独立基线审查：未发现写死的 API Key、访问令牌、密码、私钥、真实联系方式或个人目录。JS/CSS 无远程资源或数据上传接口。书籍内容输出使用 HTML 转义，嵌入 JSON 中的 `<` 被转义。

发现一个低等级本地资源问题：EPUB/DOCX 的 ZIP 条目原先没有解压预算。公开版已添加条目数、单条目大小、总解压大小和实际读取预算，并用小型合成 ZIP 进行回归测试。文件哈希改为分块读取。为减少共享提取数据时的路径暴露，公开版 `source_path` 只保留文件名。

## 排除项

- 任何真实书籍原文件、提取全文、真实书籍梳理网页和图片。
- 个人读书记录、本机路径、聊天附件、升级压缩包与其他工作区项目。
- 本机 AI 配置、环境文件、浏览器状态、凭据与安全扫描的内部记录。

仓库示例均为本项目原创，内容源文件、结构化整理和 HTML 可本地重建。发布采用明确文件白名单；首次提交仅包括审核后的公开内容，不导入旧项目历史。

## 检查方法与限制

源代码静态审查、发布文件人工阅读、白名单与敏感模式扫描、原创示例重建、引用/链接/离线结构校验和浏览器交互检查共同构成此次验证。CI 继续运行标准库测试、重建一致性与发布检查。

这不是对任意输入或未来提交的无漏洞保证。PDF 依赖内部、用户以后导入的书籍和个人笔记不属于本次审查范围。分享新的 HTML 或引入新文件时应重新检查；正则扫描没有识别语义隐私和全部凭据格式的能力。
