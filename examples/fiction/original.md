# 第一章：潮声里的灯

林禾回到海边小镇时，旧灯塔已经停用。她在门口看见守塔人周叔留下的一只铁盒，盒盖上写着：“等你愿意听的时候再打开。”她把铁盒放回原处，先沿着台阶走到塔顶。

小时候，她总以为父亲在海上看得见塔灯，所以每逢大雾就来问灯是否亮着。周叔从不催她离开，只在她身旁摆一把椅子。这次塔顶没有灯，椅子却还在。

# 第二章：没有寄出的地址

第二天，林禾打开铁盒。里面是一叠父亲写给她却没有寄出的信，每个信封都没有地址。她想起自己离开小镇时，曾说不必再告诉她海上的事。

信里没有解释那次争执，只写着一些琐事：海鸥落在船头、甲板上的水桶漏了、经过港口时看见灯塔。林禾把信带到周叔面前，问：“他为什么不寄？”周叔回答：“这个问题，要留给你们自己。”

# 第三章：把灯带回去

最后一封信只有一句话：“等你回来的时候，我想听你讲一讲陆地。”林禾这才意识到，自己一直把沉默当作拒绝，而父亲也在等她说话。她没有把这句话当作所有误解的答案。

傍晚，她在电话里告诉父亲：“我明天去港口接你。”离开灯塔时，她带走了铁盒，没有带走椅子。塔灯仍旧没有亮，但她已经知道下一步要往哪里走。
