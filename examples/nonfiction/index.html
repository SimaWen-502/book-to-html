把愿望写成能开始的动作

一个清楚的计划，应让你知道何时开始、具体做什么、到哪里算完成。

内容梳理

  • 原文将“多读一点”改写为“晚饭后读两页，并写下一句自己的理解”，用动作、时间与完成条件把愿望具体化。原书内容 · S0001 / P0002
  • 先采用普通一天也能完成的小行动，再观察真实阻力；偶尔没完成不必立即归因为能力不足。原书内容 · S0001 / P0004

内容梳理

  • 把书放在餐桌旁，并接在晚饭这个已有动作之后，可以减少临时寻找和决定的步骤。原书内容 · S0002 / P0002

把开始、完成和阻力分开记录，能帮助你决定下一轮要调整什么。

内容梳理

  • 原文建议记录是否开始、实际行动和遇到的阻力，先了解中断原因，再调整时间或任务大小。原书内容 · S0003 / P0002

写一次简单复盘

  1. 分别记录开始次数与完成次数。
  2. 列出一个最常见的阻力。
  3. 为下一轮选择一个主要调整。
