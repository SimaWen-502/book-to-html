# 一、把愿望改写为动作

“多读一点”只表达愿望，不能告诉你从哪里开始。把它改成“晚饭后读两页，并写下一句自己的理解”，动作、时间和完成条件就清楚了。

计划应先服务于开始，而不是展示雄心。第一次行动小到能在普通的一天完成，才能看见真实阻力；两页的标准可以调整，但不必把一次没完成解释为能力不足。

# 二、给行动一个固定入口

新的习惯需要容易找到的入口。把书放在餐桌旁，比临时寻找它更容易开始；在一个已有动作之后接上新动作，比只写“每天都要做”更具体。

环境安排只负责降低开始的成本，不会替你决定目标。若晚饭后常有其他安排，可以换到午休后，再观察一周。调整入口是在检验计划，而不是给自己下判断。

# 三、复盘过程，再调整计划

复盘可以分开记录三件事：是否开始、实际做了什么、遇到了什么阻力。若一周里五次开始、三次读完两页，先了解剩下两次为什么中断，再决定改时间还是改任务大小。

下一轮只改一个主要条件，更容易判断改变是否有效。记录帮助你观察自己的实践；这篇原创短文没有提供实验数据，也不宣称某种方法适用于所有人。
